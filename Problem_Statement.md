    # Problem Statement

## Project Title

**Supplier Performance Rating System**

## Domain

**Supply Chain Management**

## 1. Problem Description

Supplier performance is an important part of Supply Chain Management. Organizations need to regularly evaluate suppliers based on factors such as product quality, delivery performance, cost, communication, and complaint resolution.

Currently, supplier evaluation is often performed manually using spreadsheets and separate records. This process is time-consuming and makes it difficult to maintain supplier information, track performance, compare suppliers, and generate consistent performance ratings.

There is a need for a centralized system that can automate supplier performance evaluation and provide accurate and easily accessible supplier performance information.

## 2. Existing Problem

The existing manual supplier evaluation process has the following limitations:

- Supplier information is maintained in separate records or spreadsheets.
- Performance evaluation requires manual calculations.
- Comparing multiple suppliers is difficult.
- Supplier delivery and quality performance are difficult to track.
- Feedback and complaint information may not be maintained systematically.
- Generating supplier rankings and reports requires additional manual work.
- Manual processes can lead to inconsistent evaluation and errors.

## 3. Proposed Solution

The **Supplier Performance Rating System** is a web-based application designed to automate and simplify the supplier evaluation process.

The system will maintain supplier-related information in a centralized database and evaluate supplier performance using predefined performance factors.

The system will calculate an overall supplier rating based on:

- Quality
- Delivery Performance
- Cost
- Communication
- Complaint Resolution

The application will provide dashboards, ratings, feedback, supplier rankings, and reports to help procurement teams monitor supplier performance and make better decisions.

## 4. Target Users

### Admin

The Admin will manage users, suppliers, and overall system information.

### Procurement Manager

The Procurement Manager will:

- Manage suppliers
- Create and manage purchase orders
- Track deliveries
- Evaluate supplier performance
- View supplier ratings
- Provide feedback
- View reports and rankings

### Supplier

The Supplier will be able to view relevant supplier information, performance ratings, and feedback.

## 5. Project Objectives

The main objectives of the project are:

1. To automate the supplier performance evaluation process.
2. To reduce dependency on manual spreadsheets.
3. To maintain supplier information in a centralized database.
4. To track purchase orders and deliveries.
5. To evaluate suppliers using predefined performance factors.
6. To calculate and display supplier performance ratings.
7. To provide supplier feedback and rankings.
8. To help procurement managers make informed supplier selection and management decisions.

## 6. Main Functional Requirements

The system will provide the following major functions:

- User registration and login
- User authentication and authorization
- Supplier management
- Purchase order management
- Delivery tracking
- Supplier evaluation
- Rating calculation
- Feedback management
- Supplier ranking
- Dashboard
- Reports

## 7. Core Modules

The major modules of the system are:

### Authentication Module
Handles user registration, login, authentication, and role-based access.

### Supplier Management Module
Handles adding, viewing, updating, and managing supplier information.

### Purchase Order and Delivery Module
Handles purchase orders and tracks supplier deliveries.

### Supplier Evaluation Module
Records supplier performance evaluations and calculates supplier ratings.

### Feedback and Reporting Module
Maintains feedback and provides supplier performance information, rankings, and reports.

## 8. Scope of the Project

The project focuses on developing a centralized web application for supplier performance management.

The system will cover:

- Supplier information management
- Purchase order management
- Delivery tracking
- Supplier performance evaluation
- Rating and feedback management
- Supplier comparison and ranking
- Dashboard and reports
- User authentication and role management

## 9. Expected Outcome

The proposed system is expected to:

- Reduce manual work in supplier evaluation.
- Improve the consistency of supplier ratings.
- Provide centralized supplier information.
- Make supplier performance easier to monitor.

- Support procurement managers in making better decisions.
