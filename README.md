# Supplier Performance Rating System

## 60-Day Capstone Project

### Domain
Supply Chain Management

### Objective
Build a web-based application that enables organizations to evaluate, monitor, and rate supplier performance based on quality, delivery, cost, communication, and service metrics. The system helps procurement teams make informed supplier selection decisions through automated performance ratings, dashboards, and reports.

### Technology Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: MySQL
- API Testing: Thunder Client
- Version Control: Git & GitHub

Project planning completed.
